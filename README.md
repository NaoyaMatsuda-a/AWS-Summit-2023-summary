# Day1：AWS Summit Tokyo 2023 基調講演 （Day1）

AWSのビジョン、成長戦略、サービス初心について講説。

## 2.　主要トピック
- クラウドベースの深まる存在意識

- AWSサービスの進化（データ、セキュリティ）

- AWSサービスは「インフラ、データ、マシンラーニング、エンドツーエンドAI」まで展開
- セキュリティ安全性への素材的な執着

## 4.　自分の次の行動に繋げる気付き
- 「基盤を支える技術」に完璧はない。進化を追い続ける精神が重要

# Day2：AWS Summit Tokyo 2023 基調講演 （Day2）

## 1.　概要
AWSのデータドリブン＆サービスイノベーションによる「アイデアを形に」するための方法について講説。

## 2.　主要トピック
- データは新しい発想の源（Data beats Intuition）
- 結合：「データ戦略」の三要素
  - Comprehensive set of services
  - End-to-end integration
  - Proper governance
- ゼロETL：データ移動の自動化，時間短縮
- グラビトンCPU＆SRD＆ENA Express：パフォーマンス＆細やかなコスト削減
- オンプレミス・ローカル＆エッジ＆スペースへの展開

## 3.　とくに印象的だったポイント
- AWSのデータサービス＆イノベーションは、基礎技術＆企業成長をさらに押し上げると確信
- 「データ経営」の観点を持つことがプリセールスエンジニアにも流用できる

## 4.　自分の次の行動に繋げる気付き
- ただ技術を覚えるのではなく、ビジネス観点でデータを活用できる視点が重要
- 新技術は直結的なコスト削減にもつながり、企業成長スピードに繋がる
